## Forme `plugins.cli` in-app (plugin/cli.mdx, seule forme config validée ici)

> Under `tauri.conf.json`, you have the following structure to configure the interface.

Voir `examples/tauri.conf.cli.json` (adapté du sample doc : `plugins.cli` repris tel quel, plus `$schema` pointeur sécurité et `productName` illustratif) :

```json title="src-tauri/tauri.conf.json"
{
  "plugins": {
    "cli": {
      "description": "Tauri CLI Plugin Example",
      "args": [
        { "short": "v", "name": "verbose", "description": "Verbosity level" }
      ],
      "subcommands": {
        "run": {
          "description": "Run the application",
          "args": [
            { "name": "debug", "description": "Run application in debug mode" },
            { "name": "release", "description": "Run application in release mode" }
          ]
        }
      }
    }
  }
}
```

> All JSON configurations here are just samples, many other fields have been omitted for the sake of clarity.

- `args[]` : chaque entrée exige `name` ; clés doc seules `name/short/description/takesValue/multiple/possibleValues/index`.
  - Positionnel : `name` + `index` + `takesValue` (ex `source` 1, `destination` 2, `./app tauri.txt dest.txt`).
  - Nommé : `name` + `short`/`takesValue`/`multiple`/`possibleValues` (ex `type -t`, `./app --type foo,bar`).
  - Flag : `name` + `short` seul (ex `verbose -v`, occurrences comptées).
- `subcommands{nom: {description, args[]}}` : même forme que la racine (ex `branch`, `push`, `run`).
- Interdit : `cli` à la racine (toujours `plugins.cli`). `$schema` éventuel contient `gen/schemas` (ex `../gen/schemas/desktop-schema.json`, voir `security/capabilities.mdx` → skill sécurité).
- `{/* TODO: List available configuration */}` dans la fiche : la liste exhaustive vit dans le généré, pas ici.

## Fusion `--config` + plateforme (même mécanisme que `develop/configuration-files.mdx`, détail chez `tauri-ipc-bridge`)

- `--config` (raw JSON ou fichier JSON/JSON5/TOML) fusionné via JSON Merge Patch (RFC 7396), dans l'ordre fourni.
- Fichiers `tauri.{linux,windows,macos,android,ios}.conf.json` fusionnés par défaut ; objets fusionnés clé par clé, **tableaux remplacés** (répéter tout ce qu'on veut garder).
- Overrides documentés par variables (environment-variables.mdx) : `APPLE_SIGNING_IDENTITY` écrase `bundle > macOS > signingIdentity`, `APPLE_PROVIDER_SHORT_NAME` écrase `providerShortName`, `APPLE_DEVELOPMENT_TEAM` écrase `bundle > iOS > developmentTeam`.

Valider avec `python3 scripts/check-config-cli.py --config examples/tauri.conf.cli.json`.
